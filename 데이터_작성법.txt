=====================================================
  걸어 다니는 방탈출 - 만드는 법
=====================================================

구조는 세 가지만 기억하면 됩니다.

  1) 방 하나 = 맵 하나        (그림은 맵의 '원경'으로 깔기)
  2) 조사할 물건 = 이벤트      (이벤트 '이름'만 데이터 파일의 id와 똑같이)
  3) 지나가면 안 되는 곳 = 리전 1번 칠하기

대사, 자물쇠, 퀴즈, 아이템 같은 내용은 전부 data/EscapeData.json 한 파일에 들어 있습니다.


-----------------------------------------------------
조작법 (학생용)
-----------------------------------------------------
  방향키 / 마우스 클릭 : 걷기
  Enter, Space, 클릭  : 앞에 있는 물건 조사 (가까이 가면 이름표가 뜸)
  ESC, X, 오른쪽 클릭  : 가방 (모은 물건 보기, 힌트 보기)
  H                   : 힌트
  문은 걸어 들어가면 열립니다.


=====================================================
A. MV 편집기에서 하는 일
=====================================================

■ 맵 만들기
  맵 목록에서 오른쪽 클릭 → 새로 만들기(또는 편집)
  - 크기: 폭 29, 높이 13  (가운데 17칸 = 실제 방, 양옆 6칸씩 = 바깥 장식 마당)
    ※ 화면 비율 자동 맞춤(v2.6): 4:3 기기는 가운데 17칸만, 16:9는 양옆 3칸씩,
       휴대폰 가로는 거의 29칸 전부가 보입니다. 지도는 늘 가운데에 고정됩니다.
    ※ 단서·자물쇠·문 같은 꼭 필요한 것은 반드시 가운데 17칸(x 6~22) 안에 두세요.
       양옆 6칸은 리전 1번(벽)으로 모두 칠해 두면 주인공이 들어가지 않습니다.
  - 원경: img/parallaxes 폴더의 그림을 고르고 "에디터에 표시"에 체크
    ※ 그림 이름을 느낌표로 시작하면(!bg_palace) 그림이 바닥에 딱 붙어 움직이지 않습니다.
  - 타일은 칠하지 않아도 됩니다.

■ 원경 그림 규칙
  - 크기 1392 x 624 (= 29칸 x 13칸, 한 칸 48픽셀). 가운데 816픽셀이 실제 방
    (옛날 816 x 624 그림도 폭 17 맵에서는 그대로 쓸 수 있어요. 그때는 양옆이 검게 보일 수 있습니다.)
  - 위에서 내려다본 방 그림
  - 맨 위 한 줄(48픽셀)은 시간·버튼 표시줄이 덮으니 벽/지붕을 그려 두세요.

■ 벽 칠하기 (리전)
  1) 맵 모드(F5)에서 왼쪽 타일 팔레트 아래쪽 탭 중 [R] 탭을 누릅니다.
  2) 팔레트에서 1번을 고르고, 벽과 가구 칸을 칠합니다. (지우려면 0번)
  → 리전 1번 칸은 주인공이 지나갈 수 없습니다.

■ 등장인물(NPC) 놓기
  이벤트를 만들고 이름을 데이터 파일 id로 적은 뒤, 이벤트 그림에서 캐릭터를 고르면 됩니다.
  말을 걸면 주인공 쪽으로 돌아봅니다.

■ 조사할 물건 놓기 (이벤트)
  1) 이벤트 모드(F6)로 바꾸고, 물건이 있는 칸을 더블클릭합니다.
  2) 이름 칸에 데이터 파일의 id를 적습니다.  예: box
  3) 우선순위·트리거·실행 내용은 그대로 두고 확인. (플러그인이 알아서 처리합니다)
  - 큰 물건(보관대, 가마)은 같은 이름의 이벤트를 여러 칸에 놓으면 됩니다.
    가장 빠른 방법: 이벤트 하나 만들고 Ctrl+C, 옆 칸 클릭 후 Ctrl+V
  - 문처럼 "걸어 들어가면" 반응해야 하는 곳은 트리거를 [플레이어로부터 접촉]으로 바꾸세요.
    (그냥 두어도 문 앞에서 Enter를 누르면 열립니다)
  - 데이터 파일에 없는 이름의 이벤트는 보통 MV 이벤트처럼 동작합니다.

■ 맵 번호 확인
  맵 목록에서 맵을 고르면 편집기 아래쪽 상태줄에 맵 번호(예: 001)가 보입니다.
  이 번호를 데이터 파일의 "map"에 적습니다.

■ 좌표 확인
  맵 위에 마우스를 올리면 편집기 아래쪽 상태줄에 칸 좌표(예: 14,11)가 보입니다.
  (넓은 맵에서는 실제 방의 왼쪽 벽이 x=6, 오른쪽 벽이 x=22입니다)
  "start"(도착 위치)와 "go"의 x, y에 씁니다.

■ 제작 도우미
  플러그인 관리 → EscapeRoom → "제작 도우미 보기"를 [보기]로 바꾸고 테스트하면:
  - 빨간 칸 = 벽(리전 1번)
  - 노란 칸 = 데이터 파일과 연결된 조사 이벤트 (이름 표시)
  - 파란 칸 = 연결되지 않은 일반 이벤트 (이름 오타가 있으면 여기 파랗게 보임)
  - 화면 아래: 주인공 좌표, 그리고 "이벤트가 없는 조사 지점" 목록
  다 만들면 꼭 [숨기기]로 돌려 놓으세요.


■ 효과음 바꾸기
  플러그인 관리 → EscapeRoom을 더블클릭하면 '효과음: 문 열림 / 퍼즐 해결 / 아이템 획득 /
  시간의 문 / 시대 이동' 칸이 있습니다. audio/se 폴더에 있는 파일 이름(확장자 빼고)을 적으세요.
  칸을 비우면 그 효과음은 나지 않습니다.


=====================================================
B. 데이터 파일(EscapeData.json) 쓰는 법
=====================================================
메모장이나 VS Code로 열어 고칩니다. (VS Code는 오류를 빨갛게 표시해 줘서 편해요)
고친 뒤 게임이 안 켜지면 화면에 오류 위치가 나옵니다.
대부분 쉼표(,) 빠짐, 따옴표(") 짝 안 맞음, 괄호 짝 안 맞음입니다.

-----------------------------------------------------
1. 기본 설정
-----------------------------------------------------
  "title"        게임 제목
  "timeLimit"    제한 시간(초). 1200 = 20분, 0 = 제한 없음
  "hints"        힌트 횟수. 0이면 힌트 버튼이 사라짐
  "wrongPenalty" 오답일 때 줄어드는 시간(초). 0 = 감점 없음
  "startRoom"    처음 시작하는 방의 id

  ▶ 타이틀 · 음악 · 영상 (맨 위에 적는 설정)
  "gameTitle":  "시간의 문: 고려를 건너다"   게임 이름 (창 제목에도 쓰임)
  "titleImage": "TimeGate_Title"           img/titles1 폴더의 타이틀 그림 (1392x624 권장, 가운데 816이 기본 화면)
  "titleText":  false                      그림에 이름이 이미 들어 있으면 false (글자를 따로 안 씀)
  "titleBgm":   "Goryeo_Title"             타이틀 화면 음악 (audio/bgm)
  "bgm":        "Goryeo_Explore"           방에서 기본으로 나오는 음악
  "endingBgm":  "Goryeo_Finale"            탈출 성공 후 엔딩 음악
  방마다 다른 음악을 쓰려면 방 설정에 "bgm": "Goryeo_Tension" 처럼 적습니다.
  * 음악은 .ogg(컴퓨터용)와 .m4a(휴대폰·웹용) 두 가지를 같은 이름으로 넣어 두세요.
  * 파일이 없으면 그 음악·그림만 건너뛰고 게임은 정상 진행됩니다.


  ▶ 후기 링크 (엔딩이 끝난 뒤)
  "review": { "url": "https://forms.gle/....",
              "picture": "cu_review",
              "text": "끝까지 함께해 줘서 고마워요! Enter나 클릭을 누르면 후기 페이지가 열려요." }
  * 엔딩 정리가 끝나면 안내 화면이 나오고, Enter·클릭을 누르는 순간 링크가 열립니다.
    (컴퓨터에 설치한 게임은 기본 브라우저로, 웹으로 올린 게임은 새 탭으로 열려요)
  * 주소를 바꾸면 cu_review.png 그림 속 QR도 새로 만들어야 합니다. 원하시면 만들어 드릴게요.
  * 후기를 받지 않으려면 "review" 부분을 통째로 지우세요.


-----------------------------------------------------
2. 방 (rooms)
-----------------------------------------------------
  { "id": "palace",                 ← 방 이름표(영어/숫자)
    "name": "918년 · 개경 왕궁",      ← 화면 왼쪽 위에 보이는 이름
    "map": 1,                        ← MV 맵 번호
    "start": [14, 11, "up"],         ← 이 방에 들어왔을 때 서는 칸 (x, y, 바라보는 방향)
    "enter": [ ... ],                ← (선택) 처음 들어왔을 때 한 번 나오는 글
    "hotspots": [ ... ] }            ← 조사 지점들

  방향: "up", "down", "left", "right"

-----------------------------------------------------
3. 조사 지점 (hotspots)
-----------------------------------------------------
  { "id": "box", "label": "보물함", "steps": [ ... ] }

  id    = MV 이벤트 이름과 똑같이
  label = 그 앞에 섰을 때 머리 위에 뜨는 이름표

  ▶ 상황에 따라 다른 반응 (cases) - 위에서부터 조건이 맞는 첫 번째만 실행
    "cases": [
      { "if": { "flag": "p1" },   "steps": [ ...이미 풀었을 때... ] },
      { "if": { "item": "key" },  "steps": [ ...열쇠가 있을 때... ] },
      {                           "steps": [ ...그 밖의 경우... ] }
    ]

  ▶ 조건이 맞을 때만 조사 가능 (when)
    "when": { "flag": "p2" }

  ▶ 조건 종류
    "flag": "p1"            p1을 풀었다       "noFlag": "p1"    아직 안 풀었다
    "item": "knife"         조각칼이 있다      "noItem": "knife" 조각칼이 없다
    "items": ["a","b","c"]  셋 다 있다

-----------------------------------------------------
4. 동작 (steps) - 위에서부터 차례로 실행
-----------------------------------------------------
  { "text": "보물함이다." }                          글
  { "speaker": "도공", "text": "어서 오너라." }        이름표와 함께
  { "picture": "cu_yeonpyo", "text": "연표다." }       그림을 크게 띄우고 글 (img/pictures)
  { "give": "knife" }                               아이템 주기
  { "take": ["baekto", "jato"] }                    아이템 가져가기
  { "solve": "p1" }                                 퍼즐 해결 표시(효과음 포함)
  { "flag": "door_open" }                           표시만 하기
  { "go": "workshop" }                              다른 방으로 (그 방의 start 위치로)
  { "go": "palace", "x": 13, "y": 2, "dir": "down" } 다른 방의 원하는 칸으로
  { "escape": true }                                탈출 성공 → 엔딩
  { "penalty": 30 }                                 시간 30초 줄이기
  { "se": "Door1" }                                 효과음 (audio/se에 있는 이름. 없으면 조용히 넘어감)

  한 칸에 여러 개를 함께 써도 됩니다.
  예) { "give": "celadon", "solve": "p3", "text": "상감청자를 얻었다!" }

  ▶ 영상 · 음악 바꾸기
  { "movie": "intro_goryeo" }   movies 폴더의 영상(.webm 컴퓨터용 + .mp4 휴대폰용)을 재생
                                재생 중 Enter·클릭으로 건너뛸 수 있습니다.
  { "bgm": "Goryeo_Tension" }   음악 바꾸기,  { "bgm": "" } 음악 끄기

  ▶ 효과 (effect) - 다른 동작과 한 칸에 함께 써도 됩니다
  { "effect": "door", "target": "exit" }      target 이벤트 자리에서 빛·불꽃이 터지고 문 열리는 소리
  { "effect": "flash", "color": [255,255,255,200], "duration": 30 }   화면 번쩍 (빨강,초록,파랑,세기)
  { "effect": "shake", "power": 5, "duration": 24 }                  화면 흔들림
  { "effect": "sparkle", "target": "box" }    반짝이 (target을 빼면 주인공 자리)
  { "effect": "card", "text": "1170 · 무신정변" }                    큰 제목 카드
  { "effect": "gate", "target": "gate", "items": ["celadon", "tripitaka", "metaltype"] }
                                              시간의 문 연출 (보물이 날아가고 하얗게 사라짐)
  * 퍼즐 해결(solve), 아이템 획득(give), 오답, 처음 들어간 방의 제목 카드는 자동으로 나옵니다.
  * "go"에 "fade": "white"를 붙이면 하얗게 번쩍이며 이동합니다 (시대 이동 느낌).

  ▶ 열린 문 표시 (조사 지점에 붙이는 설정)
  { "id": "exit", "label": "공방 문", "open": { "flag": "p4" }, ... }
  조건이 맞으면 그 자리가 계속 환하게 빛납니다 (다시 돌아와도 열린 채로 보임).
  "openStyle": "glow" 를 함께 쓰면 문 대신 큰 빛무리(시간의 문처럼)가 됩니다.

  ▶ 숫자 자물쇠
  { "lock": { "digits": 3, "answer": "918", "question": "세 자리 자물쇠다." },
    "success": [ ... ],  "fail": [ ... ] }       ← fail은 빼도 됨
  * answer는 꼭 따옴표로. 키보드 숫자로도 입력 가능, ESC로 그만두기.

  ▶ 다이얼 자물쇠 (글자·방향·색깔 등, 칸마다 돌려 맞추는 자물쇠)
  같은 보기를 여러 칸에 쓸 때:
  { "dial": { "symbols": ["↑", "→", "↓", "←"], "count": 4,
              "answer": ["↑", "←", "←", "↑"], "question": "화살표 자물쇠다." },
    "success": [ ... ], "fail": [ ... ] }
  칸마다 보기가 다를 때 (labels는 칸 위에 붙는 이름표, 빼도 됨):
  { "dial": { "labels": ["학", "구름"], "slots": [["백토","자토"], ["백토","자토"]],
              "answer": ["백토", "자토"], "question": "무늬마다 흙을 고르자." } , ... }
  * 방향키 ←→로 칸 이동, ↑↓로 돌리기, 마우스로 ▲▼ 클릭도 됨.
  * 단서 그림("picture")을 띄운 바로 다음에 다이얼을 쓰면, 그림을 보면서 풀 수 있게
    다이얼이 화면 아래로 내려갑니다.

  ▶ 선택지 퀴즈
  { "choice": ["보기1", "보기2", "보기3", "보기4"],
    "answer": 1,                                ← 정답 번호(1부터)
    "speaker": "도공", "question": "상감 기법이란?",
    "success": [ ... ], "fail": [ ... ] }
  * answer를 빼면 정답·오답 없이 고른 번호에 따라 "on1", "on2" ... 를 실행합니다.
    예) "on1": [ ...1번을 골랐을 때... ], "on2": [ ...2번을 골랐을 때... ]

  ▶ 주인공 고르기 (보통 intro에 한 번)
  { "selectCharacter": true, "question": "주인공을 골라 주세요." }
  고를 수 있는 목록은 맨 위의 "characters"에 적습니다.
  "characters": [ { "label": "남학생", "image": "$student_m" },
                  { "label": "여학생", "image": "$student_f" } ]
  image = img/characters 폴더의 캐릭터 그림 이름. 첫 번째가 기본값입니다.

-----------------------------------------------------
5. 아이템 (items)
-----------------------------------------------------
  "knife": { "name": "조각칼", "image": "item_knife", "desc": "무늬를 파내는 칼." }
  image = img/pictures의 그림 (정사각형 96x96 정도)
  가방에서 고르면 그림이 크게 뜨고 desc가 나옵니다.

-----------------------------------------------------
6. 퍼즐 목록과 힌트 (puzzles)
-----------------------------------------------------
  { "id": "p1", "name": "보물함", "hints": ["1단계 힌트", "2단계 힌트(거의 정답)"] }
  힌트는 '아직 안 푼 첫 번째 퍼즐' 것이 나오니, 푸는 순서대로 적으세요.
  id는 "solve"에 쓴 이름과 같아야 합니다.

-----------------------------------------------------
7. 도입과 엔딩
-----------------------------------------------------
  "intro":  시작할 때 나오는 steps
  "ending": { "success": [...], "fail": [...], "summary": [...] }
  성공하면 걸린 시간과 힌트 수가 자동으로 나오고, 끝나면 타이틀로 돌아갑니다.


=====================================================
C. 새 주제 만들기 순서
=====================================================
